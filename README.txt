汐见 v1.8 地点小游戏远程前端包 v0.1

请把本包解压后的 dist 文件夹合并上传到 GitHub 仓库 dongyue233/shiomi 根目录。
不要删除现有 dist/map/v1.3.3 等旧版本。

新增：
- dist/map/v1.4.0/index.js
  地图前端增加地点小游戏入口，地图底图仍从角色卡本地世界书读取，最大缩放仍为 200%。

- dist/games/core/v0.1.0/index.js
  小游戏框架。负责按需加载、弹层、地点绑定、手动写入剧情输入框。

- dist/games/kings-game/v0.1.0/index.js
  国王游戏。当前技术绑定：蓝钟（blue_bell）。

- dist/games/shiomi-cards/v0.1.0/index.js
  汐见牌局。原创三列式两胜卡牌小游戏，已完成模块，但当前不绑定现有地图地点。
  原因：现有世界书没有已经成立的赌场地点；为遵守“禁止迁移语言”，不把任何现有场所擅自改写成赌场。

边界：
- 小游戏结果不会自动修改 MVU、世界书或警务事项。
- 只有用户点击“写入剧情输入框”时才把结果放入输入框，之后是否成为剧情事实由正常剧情流程决定。
- 游戏模块按需加载，不打开时不参与地图渲染。
