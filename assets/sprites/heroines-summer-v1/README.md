# 汐见夏季立绘 v1

五位角色各六种表情，共30张独立全身透明PNG。沿用通过版春季立绘的人物形象与精致动画赛璐璐画风，换用每人固定的夏季外出服。

表情：开心、平静、惊讶、害羞、伤心、生气；默认使用平静。

服装：白羽为浅蓝碎花短袖连衣裙；美羽为白色短袖上衣与淡紫百褶短裙；千鹤为浅蓝绣球花浴衣；澪为短袖衬衫与深蓝长裤；绫乃为丁香紫短袖上衣与象牙白裙。

`manifest.json`记录人物别名、表情、尺寸、透明通道、脚部锚点与资源路径。坐标为0–1归一化值；图片建议使用 contain 完整显示。`prompts.json`记录本批实际绘制要求及公开资源参考关系。

本次发布新增夏季外置资源，角色卡当前版本及春季资源继续保留。
